# Third-party code

`kit/` is a vendored subset of the [RAD Debugger](https://github.com/EpicGamesExt/raddebugger)
source (`src/`), copyright Epic Games Tools, MIT licensed (`kit/LICENSE-raddebugger.txt`).
The files are unmodified; `kit/KIT_COMMIT.txt` records the upstream commit. Bundled libraries under
`kit/third_party/` keep their own licenses (stb, xxHash, martins_*, radsort, ...).

`apps/*/data/icons.ttf` is the icon font from `raddebugger/data/`.
